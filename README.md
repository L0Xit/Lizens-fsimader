# Linzens-fsimader

Dieses Repository enthält ein simples, interaktives Mathematik-Tool, das in Python entwickelt wurde.

## Warum dieses Tool keine Lizenzen verletzt
1. **Keine Drittanbieter-Module:** Es greift ausschließlich auf die in Python integrierte Standardbibliothek (`math` und `sys`) zurück.
2. **Keine PyPI / Pip-Abhängigkeiten:** Dadurch müssen keine fremden Module heruntergeladen werden, die unter "Copyleft"-Lizenzen wie der GPL oder anderen strengen Open-Source-Lizenzen stehen könnten, was unerwünschte Einschränkungen für dich als Autor mitbringen würde.
3. **Python Standardbibliothek:** Die Standardbibliothek unterliegt der sehr toleranten [PSF (Python Software Foundation) License](https://docs.python.org/3/license.html). Du darfst deinen entstandenen Code frei anpassen, verändern und vertreiben.

## Ausführung
Du kannst das Skript in deinem Terminal mit folgendem Befehl ausführen:
```bash
python math_tool.py
```
